# Screens

## Core

1. Onboarding/settings entry.
2. Exercise Select with six gated cards.
3. Guided Demo.
4. Setup/Countdown with Open, 8, 10, or 12-rep set target.
5. Live Session.
6. Set Summary.
7. Workout Summary.

## Analytics

8. Analytics Home: exercise filter, recent progress, activity calendar, weekly summary.
9. Exercise Analytics: Form Score, ROM, tempo, degradation, consistency, symmetry, issue trends.
10. Day Journal: exercises, sets, reps, Form Score for selected day.
11. Session Journal Entry: sets, timeline, issues, feedback, metrics, optional note.

Use scrollable single-column layouts on compact screens. Trend visuals require text summaries, semantics, and non-color status cues. Missing values create gaps, never zeros.

Checkpoint speech uses pre-set, one deduplicated midpoint, and post-set messages. Targeted sets use their true midpoint; Open sets label Rep 5 as the fallback checkpoint. Live rep-by-rep coaching remains visual, not spoken.

Coaching Settings exposes independent Voice coaching, Haptic coaching, and Sound cues switches. Haptic and sound channels fire only once for each degraded rep; warning/good/calibration remain visual.

## Explicitly absent

Login/profile, cloud sync, social comparisons, clinical claims, raw-camera history.
